# Independent macOS prototype review

**Verdict: NOT READY TO SHIP AS A COHERENT FINISHED APP.** The core layout and most settings are orderly, but product information is lost, some decisions are underspecified, and dark overlays visibly break the tonal system.

## Scope and method

- Reviewed all 68 indexed macOS PNGs individually with `vision_analyze`: 34 Light and 34 Dark, each verified as a readable 1440×900 PNG. No iOS screens scored.
- Inspected the shipped Light reference for each of the 12 named routes. Reference filenames describe their supplied label, not necessarily the rendered theme (signin--light itself renders dark).
- Re-inspected small controls, permission copy, About copy, menus and composer with regional zoom. Compared overlay/base PNG pixels to resolve contradictory first-pass scrim observations.
- Score: 8 = ready to show with at most one minor nit; 9 = no material defect detected; 7 = meaningful correction needed; 5–6 = major omission or multiple substantive defects. HIGH/MEDIUM/LOW are relative product-design severity, not runtime security findings.
- This is static visual review, not click-through or accessibility certification. No claims about actual disabled states, focus trapping, backend behavior, checkout completion or measured WCAG compliance. No deduction for native traffic lights missing from content-only captures, intentional whitespace, valid ellipsis, illustrative user data, repeated overlay bases, or global-search shortcuts without inline fields.
- Source PNG for each row: `/tmp/harso-sk/proto-review/macos-<appearance lowercase>-<id>.png`.

## Cross-cutting

### D1 — HIGH: dark overlay scrim uses the wrong tonal direction

All nine inspected dark overlay variants share a lightening wash: `conversation--approval`, `conversation--delete`, `conversation--menu`, `settings--sign-out`, `settings-billing--plan`, `routines--new`, `customize--profile`, `artifacts--detail`, `search`. They turn the dark canvas into middle gray while retaining a dark foreground dialog. This is a theme-system defect, not missing scrim coverage.
