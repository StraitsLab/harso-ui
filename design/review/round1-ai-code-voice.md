## Cross-cutting

1. **Shared node/port geometry is the highest-priority fix.** Node sockets sit inside content padding; Canvas mixes recessed inputs and perimeter outputs. Wires cross card outlines. Use one shared perimeter anchoring rule and verify every connected endpoint, especially selected Work unit and Result.
2. **Center alignment leaks into reading layouts.** Transcription speaker metadata and Panel’s Instructions label lose the left reading edge shared by their content. Consistent padding does not compensate for detached labels.
3. **Wrapped copy breaks the voice grid.** Eli grows around a second description line; borders and Preview buttons lose their baseline. Equalize card heights and anchor actions while preserving text wrapping.
4. **Reference copy and action semantics drift.** Agent changes Host-selected to Most-selected and drops uncertainties from the schema; Artifact substitutes fullscreen for open. These convey different meanings and are not illustrative-data nits.
5. **Image loading placeholder needs a coherent base surface.** Its wide central gap reads as disconnected pillars. Retain a continuous base image rectangle beneath any static shimmer highlight; static motion itself is not the defect.
6. **Dark appearance is sound overall.** Dark sheets remain dark with light primary text. Identified structure defects repeat in both appearances; most AI Code geometry is clean. No widespread overlap, truncation or default-grey layout fill was established.
7. **Resolve web-reference versus lane-spec conflicts centrally.** Web Persona shows six abstract renderers, Connection a dashed in-progress graph link, Toolbar contextual Inspect/Publish/Duplicate/Remove, and OpenInChat a provider menu. Lane brief explicitly requires voice cards, a port handle, canvas toolbar and Open in Weave button. Scored explicit lane requirements, not incompatible legacy structures. Exact web parity and this specification cannot both be acceptance criteria without clarification.
